# Мої промпти

1. Створи навчальний сервіс запису до клініки з FastAPI, SQLite, JWT, seed-даними, асистентом і синтетичними даними.
2. Використай mock_llm.py без змін як LLM-заглушку; оберігай інструменти від prompt injection і перевіряй права користувача.
3. Зроби API за ТЗ: реєстрація, логін, профіль, пошук лікарів, слоти, записи, нотатки, документи, адмін-ендпоінти, health і асистентський чат.
4. Додай pytest-тести для основних сценаріїв: health, auth, profile, slots, appointments, notes, documents, admin, assistant.
5. Підготуй запуск через Docker, .env.example, README, requirements з зафіксованими версіями і готовий seed-скрипт.
