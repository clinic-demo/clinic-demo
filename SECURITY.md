# Політика безпеки

Цей репозиторій — **навмисно незахищений навчальний застосунок** курсу «Secure Software Development and Integration». Вразливості в коді застосунку є очікуваними: їх шукають і виправляють студенти в межах лабораторних робіт.

**Будь ласка, не публікуйте знайдені вразливості** в issues, pull request чи обговореннях цього репозиторію: це зіпсує завдання для наступних потоків. Обговорюйте знахідки з ментором курсу і виправляйте їх у своїй копії репозиторію.

Якщо ви помітили проблему, яка виходить за межі навчального сценарію (наприклад, справжній ключ або персональні дані в репозиторії), повідомте про це викладача курсу.

*This repository is an intentionally insecure training application. Please do not report vulnerabilities in its code publicly.*
